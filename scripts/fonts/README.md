# Fonts

`render_card.py` subsets these fonts and embeds them in the SVG, because an SVG shown through `<img>` cannot load external fonts.

- `serif-*.ttf`: Cormorant Garamond by Christian Thalmann, SIL Open Font License 1.1
- `mono-500.ttf`: JetBrains Mono by JetBrains, SIL Open Font License 1.1

Both were downloaded from Google Fonts.
